  harness around an AI coding agent (CLAUDE.md / AGENTS.md, permissions, hooks, skills, tools).
- **[Agent Atlas](https://agentatlas-dev.vercel.app)** — Bilingual (EN/ES) guide to harness engineering
  for AI coding agents, with runnable templates.
